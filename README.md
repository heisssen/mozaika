# Мозаїка: Нашвидкуруч! — система для Foundry VTT

Неофіційна система для [Foundry VTT](https://foundryvtt.com) v14 для гри **«Мозаїка: Нашвидкуруч!»**. Це кооперативна рольова гра
в яскравому сюрреалізмі й абсурді: без ведучого, без підготовки та без граників.

**Встановлення:** Foundry → *Game Systems* → *Install System* → у полі *Manifest URL* вставити:

```
https://github.com/heisssen/mozaika/releases/latest/download/system.json
```

Мова інтерфейсу: *Configure Settings → Core → Language → Українська*. Сторонні модулі не потрібні.

## Що вміє

- **Панель Мозаїки** — спільна для всіх. Має чотири фази:
  - *налаштування*: безпека «Ок / Не ок», сутності й порядок за столом, Запити для сусіда праворуч, Задача, опції;
  - *гра*;
  - *епілоги*;
  - *хроніка*.
- **Таймер Архітектора**, синхронізований для всіх (60 с або скільки задасте). Поки Архітектор говорить, решта може
  записувати реалії за ним. Після монологу Архітектор отримує уламок.
- **«Новий вимір!»**: попередній Архітектор передає роль кому захоче, вимір отримує назву. Для кожного виміру за бажанням створюється нова сцена.
- **Реалії виміру**: додає будь-хто. Змінити вже сказане можна тільки за уламок: стара реалія закреслюється.
- **Уламки**: кожну дію видно карткою в чаті.
  - вручити з причиною (причини взяті із зіна);
  - подарувати;
  - витратити на зміну реалії або сутності (зміна чужої сутності лише за згодою власника) чи на підсилення;
- **Аркуш сутності**:
  - три таблиці d10, кидок, введення будь-яких цифр («з останніх 3 цифр»);
  - Запит з архівом знайдених відповідей;
  - журнал змін, адже сутність не знищується, лише змінюється.
- **Розпад Мозаїки** (опційне правило): кожен наступний монолог на 5 с коротший; на нулі гра завершується.
- **Епілоги** по 30 с кожному. Кожен вимір, усі реалії та епілоги автоматично потрапляють у журнал-**хроніку**.
- **X-картка**: ставить таймер на паузу й анонімно просить прибрати момент.
- **Компендіуми**: таблиці сутностей, приклади ТРОН і МУМІ-ТУМІ, правила з поясненнями, як кожну частину автоматизовано.

Ведучий у Foundry потрібен лише технічно (хост світу). Він може грати власною сутністю нарівні з усіма.
